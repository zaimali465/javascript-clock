# 🕒 JavaScript Digital Clock

A simple, elegant digital clock built using **HTML**, **CSS**, and **JavaScript**. This project displays the current time and updates every second, with a responsive and modern UI design.

### 📱 Mobile

## ✨ Features

- **Live Clock**: Displays the current system time and updates every second.
- **Responsive Design**: Automatically adjusts layout across desktop and mobile screens.
- **Modern Aesthetics**: Includes smooth gradients, subtle shadows, and clean typography.

## 🚀 Installation

Follow the steps below to set up the project locally:

1. **Clone the repository:**
   
   git clone https://github.com/zaimali465/javascript-clock.git
Navigate to the project directory:


cd javascript-clock
Run the clock:

Open index.html in any modern web browser (Chrome, Firefox, Edge, etc.)

The live clock will display and update automatically.
